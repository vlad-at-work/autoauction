# Вопрос для поддержки MAX

## Тема: Отправка сообщений пользователю через Bot API

Здравствуйте,

Разрабатываю мини-приложение для MAX. Нужно отправлять уведомления пользователям через бота.

**Вопрос:**
Корректен ли следующий API-вызов для отправки сообщения пользователю?

```
POST https://platform-api.max.ru/messages
Headers: 
  Authorization: <BOT_TOKEN>
  Content-Type: application/json
Body: {
  "chat_id": <USER_CHAT_ID>,
  "text": "Текст уведомления"
}
```

**Контекст:**
- Пользователь уже открывал мини-приложение (бот активирован)
- `chat_id` получаем из `initDataUnsafe.chat.id` при открытии WebApp
- Нужно отправлять уведомления о новых предложениях

**Дополнительный вопрос:**
Можно ли прикрепить кнопку типа `open_app` для открытия мини-приложения с параметром `startapp`?
