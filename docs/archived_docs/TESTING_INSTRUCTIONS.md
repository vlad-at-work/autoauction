# Инструкции по тестированию AutoAuction

## Выполненная работа (Февраль 2025)

### Исправленные проблемы

**Проблема 1: Окно авторизации Vercel в мини-приложении MAX**

- **Причина:** На Vercel была включена защита деплоя (Deployment Protection)
- **Решение:** Отключена защита деплоя в настройках Vercel
- **Статус:** ✅ Исправлено

**Проблема 2: Дилер не видит бота в списке чатов после закрытия приложения**

- **Причина:** Дилер никогда не отправлял сообщение боту, поэтому чат не появлялся в списке
- **Решение:**
  - Добавлена отправка приветственного сообщения при привязке аккаунта дилера
  - Обновлены обработчики webhook для поддержки двух ботов (клиентский и дилерский)
- **Статус:** ✅ Исправлено

### Технические изменения

1. **Обновлен обработчик MAX webhook** (`src/app/api/webhooks/max/route.ts`)
   - Добавлена поддержка параметра `?bot=dealer` / `?bot=customer`
   - Отдельные обработчики команды `/start` для клиентского и дилерского ботов
   - Отправка приветственных сообщений для установки чата

2. **Обновлен обработчик Telegram webhook** (`src/app/api/webhooks/telegram/route.ts`)
   - Аналогичная поддержка `?bot=` параметра
   - Отдельные приветственные сообщения для клиентов и дилеров

3. **Добавлено приветственное сообщение для дилеров** (`src/app/api/dealerinterface/check/route.ts`)
   - Приветствие отправляется при успешной привязке аккаунта
   - Чат появляется в списке у дилера

4. **Созданы скрипты управления webhook**:
   - `setup-hooks.sh` — регистрация всех 4 webhook
   - `check-hooks.sh` — проверка статуса
   - `delete-hooks.sh` — удаление webhook

## Инструкции по тестированию

### Подготовка

1. Убедитесь, что у вас есть два телефона:
   - **Телефон 1** — для дилера (MAX или Telegram)
   - **Телефон 2** — для покупателя (MAX или Telegram)

2. Проверьте статус webhook (опционально):
   ```bash
   ./scripts/check-hooks.sh
   ```

---

### Тест 1: Приветственное сообщение клиентского бота (MAX)

**Цель:** Проверить, что `/start` работает и чат появляется в списке

1. Откройте MAX на телефоне покупателя
2. Найдите бота `id5010035001_bot` (или откройте ссылку `https://max.ru/id5010035001_bot`)
3. Отправьте команду `/start`
4. **Ожидаемый результат:**
   - Бот отправляет приветственное сообщение: "👋 Добро пожаловать... Это AutoAuction..."
   - Кнопка "📱 Открыть приложение" отображается под сообщением
   - Чат с ботом появляется в списке чатов

---

### Тест 2: Приветственное сообщение дилерского бота (MAX)

**Цель:** Проверить, что дилерский бот работает отдельно

1. Откройте MAX на телефоне дилера
2. Найдите бота `id5010035001_1_bot` (или откройте ссылку `https://max.ru/id5010035001_1_bot`)
3. Отправьте команду `/start`
4. **Ожидаемый результат:**
   - Бот отправляет приветственное сообщение: "👋 Добро пожаловать... Это AutoAuction для дилеров..."
   - Кнопка "📱 Панель дилера" отображается под сообщением
   - Чат с ботом появляется в списке чатов

### Тест 3: Полный поток привязки дилера (Issue #2)

**Цель:** Проверить, что после привязки дилера чат остается в списке

1. **Админ (компьютер):**
   - Откройте `https://autoauction-two.vercel.app/admin`
   - Войдите с учетными данными админа
   - Создайте нового дилера: `/admin/dealers/new` (укажите имя, например "Тестовый Дилер")
   - Откройте страницу дилера и скопируйте **MAX ссылку-приглашение**

2. **Дилер (Телефон 1, MAX):**
   - Откройте скопированную ссылку-приглашение в MAX
   - Приложение откроется, покажет форму установки пароля
   - Установите пароль и нажмите "Сохранить"
   - **Критически важно:** После успешной установки пароля вы должны получить приветственное сообщение от дилерского бота в чате:
     > "🎉 Добро пожаловать в AutoAuction, [Имя дилера]! Ваш аккаунт дилера успешно активирован..."
   - Кнопка "📱 Открыть панель дилера" должна быть под сообщением
   - **Проверка:** Закройте приложение (крестик вверху) → чат с ботом `id5010035001_1_bot` должен остаться в списке чатов MAX

3. **Покупатель (Телефон 2, MAX):**
   - Откройте клиентский бот `id5010035001_bot`
   - Нажмите "📱 Открыть приложение"
   - Создайте заявку на автомобиль
   - Дождитесь уведомлений о предложениях

4. **Дилер (Телефон 1):**
   - Вернитесь в чат с дилерским ботом
   - Должно прийти уведомление о новой заявке с кнопкой "📱 Открыть заявку"
   - Нажмите кнопку → откроется панель дилера
   - Сделайте предложение

5. **Покупатель (Телефон 2):**
   - Должно прийти уведомление о новом предложении с кнопкой "📱 Посмотреть предложения"
   - Нажмите кнопку → откроется заявка
   - Примите предложение

6. **Дилер (Телефон 1):**
   - Должно прийти уведомление: "🎉 Покупатель принял ваше предложение!"

### Если что-то не работает

| Проблема                          | Решение                                                 |
| --------------------------------- | ------------------------------------------------------- |
| Нет приветственного сообщения     | Проверьте статус: `./scripts/check-hooks.sh`            |
| "Unknown recipient" при отправке  | Пользователь должен сначала написать боту `/start`      |
| Кнопки не открывают приложение    | Проверьте, что `NEXT_PUBLIC_APP_URL` установлен         |
| Дилер не видит чат после закрытия | Убедитесь, что приветственное сообщение было отправлено |
| Webhook не работает               | Проверьте логи Vercel, перерегистрируйте webhook        |
